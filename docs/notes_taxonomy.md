# Mentor Notes Taxonomy

## Core principle

Use the existing fields:

- Type
- Content
- Source
- Tags

Do not add extra fields until real usage proves the need.

## When to use each Type

**Quote**

- Verbatim mentor saying, book quote, memorable phrase.

**Rule**

- Hard rule / always-never behavior / high-conviction process rule.

**Lesson**

- Specific learned pattern from mentor, past trade, or review.

**Idea**

- Hypothesis, untested concept, observation to revisit.

## How to encode concepts without extra fields

**Confidence**

- `Rule` = high-conviction behavior
- `Lesson` = learned from context
- `Idea` = lower-confidence hypothesis
- Optional tags: `#high_conviction`, `#needs_review` if ever needed

**Applies to**

Use tags:

- `#s50`
- `#gold`
- `#silver`
- `#usdjpy`
- `#all_markets`
- `#sideway`
- `#trend`
- `#breakout`
- `#range`

**Invalidation / expiry**

- Put at the end of Content only when important.
- Example:

  > Invalidation: ถ้าตลาดทำ HH/HL พร้อม follow-through ชัดเจน rule นี้ไม่ใช่การห้าม trade แต่เปลี่ยนเป็นรอ breakout setup.

## Suggested tag groups

**Market / Instrument**

`#s50` `#gold` `#silver` `#usdjpy` `#all_markets`

**Behavior / Psychology**

`#fomo` `#overtrade` `#force_narrative` `#process_over_outcome`

**Risk / Setup**

`#risk_control` `#falling_knife` `#advantaged_zone` `#partial_tp`

**Regime / Context**

`#sideway` `#trend` `#breakout` `#range`

**Process**

`#trade_management` `#trade_selection` `#entry` `#exit`

## Source convention

Use:

- `mentor`
- `พี่โอห์ม`
- `book: <title>`
- `self-rule`

Default for mentor-taught lessons: `mentor`
